# wideamari: what to paste where

You paste 2 things. Nothing else is needed.

## 1. Channel settings → General settings → External Javascript

Paste this link into the External Javascript box, then save:

```text
https://nostramadeus.github.io/wideamari-js/wideamari-extra.js
```

## 2. Channel settings → Edit → JavaScript

Delete everything in the box, paste this, then save:

```text
/*! The wideamari channel script is loaded from Channel settings → General settings → External Javascript:
 * https://nostramadeus.github.io/wideamari-js/wideamari-extra.js
 * (source: https://github.com/Nostramadeus/wideamari-js). Nothing else needs to be in this box. */
```
